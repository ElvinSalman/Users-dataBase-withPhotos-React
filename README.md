# Users Database with Photos (React)

A React application that provides a simple user management interface with photo support: view, add, edit, and delete users.

---

## 🔍 Overview

This project demonstrates a frontend solution for managing a user database, including:

- Displaying a list of users with profile photos  
- Adding new users with photo upload  
- Editing user data (name, email, photo, etc.)  
- Deleting users  
- (Optional) Search, filter, or sort functionality  

The app is built with React and styled with modern UI practices.

---

## ⚙️ Features

- User list display  
- Form to add new users  
- Photo upload for user profiles  
- Edit existing user information  
- Delete users from the list  
- Input validation (name, email, photo)  
- State management using React Hooks / Context / Redux (depending on implementation)  
- Responsive layout  

---

## 🛠 Tech Stack

- **React**  
- JavaScript (or TypeScript if configured)  
- **Axios** / Fetch API (for backend communication)  
- **CSS / SCSS / Tailwind / Styled Components** (styling)  
- JSON Server / Mock API (if backend is not connected)
